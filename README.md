# SQL-Exploratory-Data-Analytics-Project
A comprehensive collection of SQL scripts for data exploration, analytics, and reporting. These scripts cover various analyses such as database exploration, measures and metrics, time-based trends, cumulative analytics, segmentation, and more.

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA) using SQL** to understand the dataset, identify patterns and trends, analyze key metrics, and extract meaningful insights.

The project demonstrates how SQL can be used to transform raw data into actionable insights through **data cleaning, aggregation, filtering, subqueries, CTEs, and window functions**.

## 🎯 Objectives

* Understand the structure and characteristics of the dataset
* Explore data using SQL queries
* Identify trends, patterns, and anomalies
* Analyze key business metrics
* Perform customer/product/category-level analysis
* Use advanced SQL techniques to answer analytical questions
* Generate meaningful insights from raw data

## 📊 Analysis Performed

### 1. Data Exploration

Initial exploration was performed to understand:

* Number of records
* Number of columns
* Data types
* Unique values
* Missing or inconsistent data
* Distribution of important variables

### 2. Data Cleaning

SQL queries were used to:

* Identify duplicate records
* Check for NULL values
* Detect inconsistent entries
* Validate data quality

### 3. Descriptive Analysis

Aggregations were used to calculate:

* Total values
* Averages
* Minimum and maximum values
* Counts
* Category-wise performance
* Time-based trends

### 4. Advanced Analysis

Advanced SQL techniques were used to answer analytical questions involving:

* Rankings
* Top and bottom performers
* Category comparisons
* Customer-level analysis
* Running totals
* Percentage contribution
* Period-over-period comparisons

## 🧠 Key SQL Techniques Demonstrated

### CTEs

Used to break complex analytical problems into smaller, readable query steps.

### Window Functions

Used for:

* Ranking
* Running totals
* Partition-based calculations
* Comparing records across rows

### Subqueries

Used to perform nested analysis and compare individual records against aggregated results.

### Conditional Logic

`CASE WHEN` was used to create categories and perform conditional analysis.

The analysis identifies important patterns and relationships within the dataset, including:
